# 주간 실습 수업 준비 도구 요구사항 제안서

## 1. 목적

매주 일요일에 다섯 과목의 수업을 준비하는 부담을 줄인다. 기존 판서 사진과 실제 수업 진행 기록을 바탕으로 다음 수업의 실습 방향을 제안하고, 교수자가 선택·수정하여 사용할 실습 진행안과 칠판용 핵심 요약을 만든다.

전자책 원문을 직접 읽거나 교재 순서를 자동으로 파악하는 기능은 포함하지 않는다. 제안은 제공된 수업 기록과 교수자가 알려주는 진도를 근거로 작성한다.

## 2. 수업 운영 조건

| 과목 | 수업 시간·학생 구성 | 주요 실습 환경 |
|---|---|---|
| 월 오전·블로그 | 3시간, 2학년 중심 | Adobe Bridge·Camera Raw, 사진 이미지 제작·활용 |
| 월 오후·유튜브 콘텐츠 제작 | 3시간, 오전과 대부분 같은 학생 | Adobe Bridge·Camera Raw, 콘텐츠용 이미지 제작·활용 |
| 화·영상 제작 기초 | 반별 2시간, 서로 다른 3개 반에 반복 | 미러리스·DSLR·표준 렌즈, 팀별 기획과 촬영 |
| 수 오전·쇼츠 제작 | 3시간, 월요일과 대부분 겹치는 2학년 | Premiere Pro, 쇼츠 편집·제작 |
| 수 오후·미디어 채널 운영 | 3시간, 별도의 3학년 학생 | ChatGPT 중심, Gemini·NotebookLM 병행 |

각 수업의 약 절반을 실습 시간으로 사용한다. 3시간 수업은 약 90분, 화요일은 반별 약 60분을 실습안의 기본 기준으로 삼는다. 실제 시간 배분은 교수자가 조정할 수 있어야 한다.

현재 5주차까지 수업을 마쳤으며, 향후 준비 대상은 6~7주차와 9~14주차이다. 평가가 있는 8주차와 15주차는 일반 실습 제안에서 제외한다.

## 3. 결과물의 우선순위

### 1순위: 학생 실습 진행안

학생들이 무엇을 하고 어디까지 완성해야 하는지 명확히 제시한다.

각 실습안에는 다음 항목을 포함한다.

- 실습 제목과 학습 목표
- 완성할 결과물과 최소 완료 기준
- 필요한 장비·프로그램·기존 자료
- 단계별 작업 순서와 예상 시간
- 개인 또는 팀별 진행 방식
- 교수자의 시연·중간 확인 지점
- 학생이 확인할 점과 자주 막힐 수 있는 부분
- 시간이 부족할 때 줄일 작업과 빠르게 마친 학생의 추가 작업

화요일 팀 실습에는 역할 분담, 촬영 준비, 촬영 순서, 조원별 참여와 결과 리뷰 방법을 추가한다.

### 2순위: 칠판용 핵심 요약

선택한 실습안과 연결되는 짧은 판서 내용을 만든다.

- 오늘의 목표
- 꼭 알아야 할 개념과 용어
- 필요한 설정값 또는 설정 기준
- 작업 순서
- 주요 주의점
- 완료 기준

설정값은 제공된 기록에 있는 값과 새롭게 제안하는 예시를 구분한다. 기존 판서처럼 핵심 단어, 짧은 문장, 화살표와 간단한 도식으로 정리한다.

### 3순위: 교수자용 보충 설명

자세한 설명 노트는 기본 결과물에 포함하지 않는다. 교수자가 요청한 개념이나 불확실한 부분에 한해 보충한다.

## 4. 입력 자료와 기록 관리

기본 입력은 판서 사진과 교수자의 짧은 수업 메모이다.

사진별로 촬영 날짜, 판서 날짜, 과목명, 판서 번호, 핵심 개념, 실습 지시, 다음 수업 안내를 정리한다. 날짜나 글씨가 불분명하면 확인이 필요한 항목으로 표시한다.

다음 사항은 사진만으로 확정하지 않는다.

- 판서 번호와 학기 주차의 관계
- 학생들이 실제로 완료한 작업
- 학생들의 이해도
- 사진이 없는 날의 수업 진행 여부
- 교재에서 다음에 나오는 내용

수업 후에는 교수자가 완료한 내용, 미완료 작업, 학생들이 어려워한 부분을 짧게 추가할 수 있어야 한다. 화요일은 이 기록을 세 반별로 구분한다.

## 5. 핵심 기능

### F01. 날짜·과목별 기존 수업 정리

판서 사진을 날짜와 과목별로 분류하고 수업 흐름을 요약한다. 각 요약이 어느 사진에서 나온 것인지 추적할 수 있어야 한다.

### F02. 실제 진도를 반영한 다음 실습 제안

지난 기록을 바탕으로 다음 수업에 적합한 실습 방향을 제안한다. 제안마다 이전 수업과의 연결 이유, 필요한 선행 작업, 예상 결과물을 설명한다.

학생 이해도가 부족하거나 미완료 작업이 있으면 복습·완성 중심의 실습을 우선 제안한다. 정보가 없으면 그 사실과 제안의 가정을 명시한다.

### F03. 실습안과 판서 요약의 동시 작성

교수자가 실습 방향을 선택하면 시간에 맞는 진행안과 칠판 요약을 함께 만든다. 실습안의 목표·용어·순서와 판서 내용이 일치해야 한다.

### F04. 2학년 세 과목의 연계

월요일 두 과목과 수요일 오전 수업에서 사진·기획안·제작물을 공유할 수 있도록 구성한다.

동일한 자료를 재사용하더라도 과목별 학습 목표와 새롭게 수행할 작업을 구분한다. 일부 과목을 수강하지 않는 학생에게는 대체 자료나 간단한 시작 단계를 제안한다.

### F05. 화요일 세 반의 반복 운영

공통 실습안을 한 번 준비하여 세 반에 적용한다. 반별 진도·이해도·미완료 사항을 별도로 기록하고, 필요한 경우 같은 실습의 분량이나 난이도를 조정한다.

교재 순서를 따르기 위해 필요한 다음 단원 정보는 교수자가 짧게 지정한다. 교재 내용이 제공되지 않으면 교재 순서에 맞는다고 단정하지 않는다.

### F06. 3학년 수업의 독립 운영

수요일 오후 수업은 별도 학습 이력을 기준으로 제안한다. AI 사용법을 실제 채널 운영 작업에 연결하고, 요청 작성·결과 검토·수정 과정을 실습에 포함한다.

### F07. 자유로운 준비 순서와 수정

교수자가 먼저 준비하고 싶은 과목부터 선택할 수 있어야 한다. 실습 주제·분량·시간·난이도·결과물을 수정하면 판서 요약에도 반영한다.

## 6. 권장 사용 흐름

1. 수업 후 판서 사진과 짧은 진행 메모를 남긴다.
2. 일요일에 준비할 과목을 선택한다.
3. 도구가 지난 수업의 핵심과 미완료 사항을 보여준다.
4. 근거가 있는 다음 실습 방향을 소수의 선택지로 제안한다.
5. 교수자가 선택하거나 수정한다.
6. 학생 실습 진행안과 칠판 요약을 완성한다.
7. 수업 후 실제 진행 결과를 다음 준비에 반영한다.

질문이 필요하면 한 번에 하나씩 묻는다. 이미 제공한 정보는 반복해서 묻지 않는다.

## 7. 기존 기록을 바탕으로 한 수업 방향 제안

다음 내용은 확정된 강의계획이 아니라 기존 수업에서 이어갈 수 있는 제안이다.

| 수업 | 제안 방향 | 이전 기록과의 연결 |
|---|---|---|
| 2학년 세 과목 | 하나의 소재와 사진·기획안을 바탕으로 블로그용 이미지, 유튜브 콘텐츠용 구성, 쇼츠 제작으로 확장 | 사진 품질·RAW 보정·이야기 구성·영상 제작의 공통 기초를 이미 다룸 |
| 화·영상 제작 기초 | 배운 노출·FPS·WB·초점 설정을 팀별 짧은 장면 촬영에 적용하고 결과 리뷰 | 인물 촬영과 카메라 설정 학습을 실제 제작에 연결 |
| 수 오후·미디어 채널 운영 | 개인 채널의 콘텐츠 아이디어를 구체화하고 AI와 기획안·스토리보드·제작 일정 작성 | 프롬프트·OCR·스토리보드·일정 공유 학습을 채널 운영 작업에 연결 |

2학년 연계 실습은 매번 새 자료를 만드는 부담을 줄이면서, 같은 자료를 목적에 맞게 변환하는 경험을 제공하는 방향이 적합하다.

화요일은 장비 설정을 반복 설명하는 데서 한 단계 나아가, 학생들이 설정을 선택하고 촬영 결과로 확인하는 실습이 적합하다. 다만 실제 다음 단원과 팀별 진행 상황을 반영하여 결정한다.

3학년 수업은 AI가 만든 결과를 그대로 사용하는 데서 그치지 않고, 자기 채널의 목적과 대상에 맞게 검토하고 수정하는 과정이 필요하다.

## 8. 첫 구현 범위 제안

우선 현재 사진 17장과 이후 수업 메모를 사용하는 작은 형태로 시작한다.

첫 구현에는 날짜·과목별 기록, 다음 실습 방향 제안, 실습 진행안, 판서 요약, 2학년 과목 연계, 화요일 반별 기록을 포함한다.

전자책 원문 접근, 학생 채널 자동 업로드, 자동 평가, 학생 개인정보 관리는 첫 구현 범위에 포함하지 않는다.

## 9. 완료 기준

- 실습안만 보고 학생이 시작 작업과 완료 기준을 이해할 수 있다.
- 기본 실습 분량이 60분 또는 90분에 맞게 구성된다.
- 칠판 요약이 선택한 실습안과 일치한다.
- 기존 기록에서 확인한 사실과 새 제안이 구분된다.
- 2학년 연계 수업의 공유 자료와 과목별 작업이 구분된다.
- 화요일 세 반의 실제 진행 기록을 각각 유지할 수 있다.
- 평가 주차가 일반 수업 준비 대상에서 제외된다.
- 교수자가 준비 순서와 내용을 자유롭게 변경할 수 있다.

## 10. 추가로 결정할 사항

실제 제작 형태, 결과물 전달 방식, 수업 후 메모 방식, 학생 장비·프로그램 숙련도는 추가 확인 후 확정한다. 준비 시간 절감 목표도 현재 소요 시간을 확인한 뒤 정한다.
